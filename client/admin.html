لوحة التحكم

صفحة خاصة بالمشرف. استخدم مفتاح service_role (secret) — يبدأ بـ sb_secret_ أو eyJ — وليس المفتاح العام publishable. هذا المفتاح وحده يسمح بالإضافة والتعديل والحذف.
تجده في: Supabase → Project Settings → API → service_role.

المفتاح يُحفظ في متصفحك فقط ولا يُرسل لأي جهة غير Supabase. استخدمه على جهازك الخاص.
